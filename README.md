# 쿠팡이츠 월별 결제 내역 엑셀 자동화

내가 원하는 월의 쿠팡이츠 결제 내역을 Gmail에서 자동으로 찾아 엑셀(.xlsx) 파일로
정리해주는 프로그램입니다.

- 쿠팡이츠 결제 메일은 아래 3개 PG(결제 대행)사 중 한 곳에서 오는데,
  이 프로그램은 세 곳을 모두 확인해서 빠짐없이 모아줍니다.
  - **NHN KCP**: 본문의 "구매상점명"이 쿠팡이츠인 메일
  - **나이스페이먼츠**: 본문의 "주문번호"가 `ROCKET_PAY_DELIVERY_`로
    시작하는 메일 (쿠팡 로켓배송 등 다른 주문은 자동으로 제외)
  - **이지페이**: 메일 속 영수증 페이지의 주문번호가
    `ROCKET_PAY_DELIVERY_`로 시작하는 메일 (이지페이는 메일 본문에
    주문번호가 없어서, 메일에 있는 "English Receipt" 링크와 똑같은
    페이지를 프로그램이 대신 열어서 확인합니다)
- Claude Code 없이도 독립적으로 동작합니다.
- 확인한 메일 내용은 이 컴퓨터 안에서만 처리되고, 결과는 `output` 폴더의
  엑셀 파일로만 저장됩니다. 외부 서버에 저장되지 않습니다.

## 최초 1회 설정

아직 설정하지 않았다면 [`SETUP.md`](./SETUP.md) 안내를 따라
`install.bat` 실행 → 구글 인증 파일(`credentials.json`) 준비까지 먼저
진행해주세요.

## 매달 사용하는 방법

1. `run.bat` 을 더블클릭합니다.
2. 검은 창이 뜨면 조회할 **연도**와 **월**을 입력합니다.
   - 연도는 그냥 엔터를 누르면 올해로 자동 입력됩니다.
3. 잠시 기다리면 결제 내역을 정리한 엑셀(.xlsx) 파일이 만들어집니다.
4. 완료 메시지에 나오는 저장 위치(`output` 폴더 안)에서 파일을 확인합니다.
   - 파일명 예시: `260800_쿠팡이츠결제내역_claudecli.xlsx` (2026년 8월인 경우)
5. 아무 키나 눌러 창을 닫습니다.

## 엑셀 파일에 담기는 항목

| 컬럼 | 설명 | 정렬 |
|---|---|---|
| 결제일시 | `결제` 건은 결제한 날짜/시각, `취소` 건은 취소(취소요청)한 날짜/시각 (`yyyy-mm-dd hh:mm`) | 왼쪽 |
| PG사 | 결제 대행사 (NHN KCP / 나이스페이먼츠 / 이지페이) | 왼쪽 |
| 상점명 | 주문한 매장 이름 (PG사에 따라 "쿠팡이츠"로 표시되거나, "쿠팡(주)"처럼 쿠팡 법인명으로만 표시될 수 있습니다) | 왼쪽 |
| 상품명 | 주문한 메뉴/상품명 | 왼쪽 |
| 결제금액 | `결제` 건은 결제 금액, `취소` 건은 그 취소로 실제 취소된 금액(부분취소 시 부분취소 금액). 천단위 쉼표 표시 | 오른쪽 |
| 구분 | `결제` 또는 `취소` (해당 건이 결제 완료 건인지, 취소/환불 건인지) | 왼쪽 |
| 주문번호 | 쿠팡이츠 주문번호 (자릿수가 길어 텍스트로 저장, 지수(E) 표기 방지) | 왼쪽 |
| 승인번호 | 카드 결제 승인번호 (숫자로 저장하되 앞자리 0은 서식으로 유지) | 오른쪽 |

- 1행 헤더에 자동 필터가 걸려 있고, 결제일시 내림차순(최신순)으로 정렬되어 있습니다.
- 한글이 깨지지 않고, 엑셀에서 바로 열어 편집/필터링할 수 있습니다.

## 참고 사항

- 이 프로그램은 결제 완료 메일과 취소/환불 메일을 모두 다룹니다. 취소/환불된
  주문은 `구분` 컬럼이 `취소`로 표시된 별도의 행으로 추가되며, 원래 결제 건과
  자동으로 상계(차감)되지는 않습니다 — 두 행을 보고 직접 확인해주세요.
- 메일 형식을 해석하지 못한 건이 있으면 실행 중 `[건너뜀]` 메시지로
  알려줍니다.
- 이지페이 메일은 건마다 영수증 페이지를 추가로 열어서 확인하기 때문에
  다른 PG사보다 시간이 조금 더 걸릴 수 있습니다. 인터넷 상태에 따라
  가끔 확인에 실패하면 `[건너뜀]` 메시지가 뜨는데, 이 경우 나중에
  `run.bat`을 다시 실행해보시면 됩니다.
- `credentials.json`, `token.json`, `output` 폴더의 엑셀 파일에는 개인
  결제정보가 들어있어 git에 올라가지 않도록 되어 있습니다(`.gitignore`).
